# ベイビュー BBS コミュニティルール

## はじめに

ようこそ、ベイビュー BBS へ。ここはベイビューに住む皆さんが、母語で気軽に会話できる **非公式の住人コミュニティ掲示板** です。運営会社の公式チャンネルではなく、住人の Shige が個人プロジェクトとして立ち上げ、運営しています。サーバ代もモデレーションも一住人としてのボランティアで行っているので、その前提でお付き合いください。

このフォーラムの目的はシンプルです。

- 共用設備（キッチン・ジム・ランドリー）の困りごとを共有する
- 譲ります／売ります／探していますの情報をやり取りする
- 近所のおいしい店や行政手続き、ゴミ出しのコツをシェアする
- イベントや勉強会を企画する
- 日々の雑談で、隣人の顔と人柄を少しずつ知る

LINE のオープンチャットや口コミでは「全員が母語で読み書きできる」体験は提供できません。住人の約 8 割が外国人というベイビューの環境に合わせ、投稿は自動翻訳されて各自の言語で表示されます。日本語で書けば韓国語・英語・ドイツ語・スペイン語・フランス語・中国語の住人にも届きます。逆もまた然りです。

## 投稿のルール

1. **敬意を持って書きましょう。** 文化・宗教・国籍・性別・性的指向・年齢・職業に対する差別的な発言は禁止です。冗談のつもりでも、相手にどう届くか分かりません。
2. **建設的に書きましょう。** 困っていること、助けてほしいこと、共有したいことを具体的に書くと、住人から良い反応が返ってきます。
3. **自分の母語で書いて構いません。** むしろそうしてください。AI が他の言語に翻訳してくれます。完璧な日本語や英語を書こうとして黙ってしまうより、自然な母語で書いた方が良い投稿になります。
4. **個人を特定できる情報は控えめに。** 他人の本名、部屋番号、写真を本人の許可なく投稿しないでください。自分の情報も、公開範囲を意識して書きましょう。
5. **カテゴリを選んでから投稿しましょう。** 譲渡情報は **Marketplace**、設備の不具合は **Laundry / Gym / Facilities**、近所の質問は **Help / Tips**、雑談は **Lounge** に。

## 禁止事項

- 差別、ハラスメント、個人攻撃
- 営利目的の宣伝、勧誘、マルチ商法、アフィリエイトリンクの貼り付け
- 出会い系・性的な内容
- 違法行為の誘発・教唆
- 他の住人のプライバシーを侵害する内容（本名・部屋番号・写真など）
- 大量の連投・コピペ・スパム的な投稿

なお、**運営会社（ベイビュー本体）への意見・批判・改善要望は禁止していません**。住人としての率直な感想は、住人同士で共有する価値があります。ただし、運営批判をこのフォーラムから運営会社に直接ぶつけるのはやめてください。あくまで非公式の場であり、公式チャンネルではありません。

## モデレーション方針

- このフォーラムは Shige の個人運営です。プロのモデレーターはいません。
- 違反が疑われる投稿を見つけたら、投稿の **通報ボタン** からお知らせください。日本語以外の通報メモも歓迎です。
- 通報内容を確認した上で、投稿の編集・非公開・削除、ユーザーの一時停止などの対応を行います。最終判断は Shige にあります。
- 判断に納得がいかない場合は **Site Feedback** カテゴリ、または DM／LINE で直接ご連絡ください。

## プライバシー

- 本名や部屋番号は公開する必要はありません。プロフィールに **フロアのみ表示／非公開** などの設定があります。
- 自分の写真をプロフィールに使うかどうかは自由です。
- 他の住人の顔写真、子どもの写真は **本人の同意なく投稿しないでください**。ベイビュー内の共用部の写真は、人物が写っていなければ問題ありません。
- 退去時に「過去の自分の投稿を消してほしい」と希望する場合は、Shige に連絡してください。原則として対応します。

## 翻訳について

- 投稿は Mac Mini 上のローカル LLM で自動翻訳されます。クラウド翻訳サービスは使っていないため、原文・翻訳ともにベイビュー外のサーバには送信されません。
- 自動翻訳の精度は完璧ではありません。特に皮肉、駄洒落、専門用語、地域固有の言い回しは誤訳されがちです。
- **投稿本文をクリックすると、原文と翻訳をいつでも切り替えられます。** 翻訳が変だと感じたら原文を確認してください。
- 自分の母語と投稿の元言語が同じ場合は、原文がそのまま表示されます。

## 連絡先

- フォーラム上での質問は **Site Feedback** カテゴリへ。
- 個別の相談は Discourse 内の DM、または LINE の Shige 個人アカウントへ。LINE ID は希望者にお伝えします。
- 運営トラブルや緊急の連絡は LINE の方が反応が早いです。

このフォーラムが、ベイビューでの日々を少しだけ豊かにする場所になれば嬉しいです。よろしくお願いします。

— Shige
