# 灣景論壇社群規範

## 緒言

歡迎光臨貝維尤 BBS。這裡是一個非正式的住戶社群公告欄，居住於貝維尤的各位可以在這裡以各自的母語輕鬆交流。這不是任何營運公司的官方頻道，而是由住戶 Shige 以個人專案的方式創立並維護。由於伺服器費用和管理工作皆由一位住戶以志願的方式進行，敬請諒解。

這個論壇的宗旨非常簡單。

- 共享共用設施（廚房、健身房、洗衣房）的相關問題與困難。
- 轉讓、出售、以及尋找相關資訊的交流。
- 分享附近美味的餐廳、行政手續以及垃圾處理的技巧。
- 舉辦活動或讀書會。
- 在日常的閒話中，逐漸了解鄰居的容貌和品性。

LINE 的開放聊天以及口碑分享，無法提供「所有人都能以自己的母語閱讀和書寫」的體驗。 考量到貝維尤區域居住者約八成是外國人士，因此，發布的內容會自動翻譯，並以每位使用者的語言顯示。 即使您以日語書寫，也能傳達給居住在韓國、英語、德語、西班牙語、法語及中國語的使用者。 反之亦然。

## 投稿規則

1. 請以尊重的態度書寫。嚴禁任何基於文化、宗教、國籍、性別、性傾向、年齡或職業等因素的歧視性言論。即使是開玩笑，也無法預知對方如何接收。
2. 請以建設性的方式發文。具體描述您遇到的問題、需要協助的事項，以及想要分享的內容，這樣才能獲得其他住戶的良好回覆。
3. 請用您的母語書寫。 甚至，請這麼做。 AI 可以將其翻譯成其他語言。 與其為了寫出完美的日語或英語而猶豫不前，不如用您最自然的母語書寫，這樣才能產生更好的內容。
4. 請盡量避免透露可識別個人身份的資訊。請勿在未經當事人同意的情況下，發布他人的姓名、房間號碼或照片。對於您自身的信息，也請注意公開範圍，謹慎發布。
5. 請先選擇類別再發布內容。 關於轉讓資訊，請至 **Marketplace**；關於設備故障，請至 **Laundry / Gym / Facilities**；關於鄰里疑問，請至 **Help / Tips**；至於閒聊，請至 **Lounge**。

## 禁止事項

- 歧視、騷擾、人身攻擊。
- 用於營利的宣傳、招攬、多層傳銷，以及置入聯盟連結。
- 交友及性相關內容。
- 違法行為的誘導與教唆。
- 其他住戶的隱私資訊，例如：真實姓名、房間號碼、照片等。
- 大量的重複發文、複製貼上內容以及垃圾訊息。

此外，**對運營公司（貝維尤公司）的意見、批評或改善建議，並未禁止**。作為住戶，誠實地表達您的感想，與其他住戶分享是很有意義的。但請避免直接透過本論壇向運營公司提出負面批評。這裡僅是一個非正式的平台，並非官方渠道。

## 版運規範

- 此論壇由 Shige 個人維護。沒有專業的版主。
- 如果您發現任何疑似違規的內容，請透過內容的 **檢舉按鈕** 進行回報。即使是使用其他語言撰寫的檢舉備註，我們也歡迎。
- 確認了通報內容後，將根據情況對發布內容進行編輯、隱藏或刪除，並可能對使用者進行暫時限制等處理。最終決策由 Shige 決定。
- 如果您對判斷結果有任何疑慮，請前往 **網站回饋** 類別，或直接透過 DM/LINE 與我們聯繫。

## 隱私

- 不必公開真實姓名或房間號碼。個人資料中設有「僅顯示樓層／不顯示」等選項供您設定。
- 您可以自由地選擇是否在個人資料中使用您的照片。
- 其他住戶的肖像照片、兒童照片，請勿在未經本人同意的情況下發布。若是在貝維尤內共用區域拍攝的照片，只要未包含人物，則沒有問題。
- 如果您在離開時希望刪除過去的發文，請與 Shige 聯繫。我們原則上會處理您的請求。

## 關於翻譯

- 投稿內容將由 Mac Mini 上的本地大型語言模型自動翻譯。由於未使用雲端翻譯服務，原文與翻譯內容均不會傳送至位於灣區以外的伺服器。
- 自動翻譯的準確性並非完美無缺。尤其是在處理諷刺、雙關語、專業術語以及各地方言表達時，容易出現翻譯錯誤。
- 點擊投稿本文，隨時可以切換顯示原文與翻譯。 若您覺得翻譯有偏差，請查閱原文。
- 如果您的母語與發文的原始語言相同，則會直接顯示原文。

## 聯絡方式

- 論壇上的提問，請發布至「網站回饋」類別。
- 若需個別諮詢，請透過 Discourse 站內私訊，或聯繫 Shige 的 LINE 個人帳號。LINE ID 將另行告知有興趣者。
- 對於營運上的問題或緊急聯絡，LINE 的回覆速度通常更快。

希望這個論壇能為您在貝維尤的每一天增添一些色彩。 期待與您交流。
